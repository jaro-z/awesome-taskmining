# Contributing

Thanks for your interest in contributing to Awesome Task Mining!

## Guidelines

1. **One resource per pull request.** Keep PRs focused and easy to review.
2. **PR title format:** `Add [resource-name]`
3. **Link format:** `- [Name](url) - Short description ending with a period.`
4. **Describe why it's awesome.** Include a sentence in the PR description about what makes this resource valuable.
5. **Search for duplicates** before submitting.
6. **Check your links.** Make sure URLs are working.
7. **Spell check** your submission.
8. **New sections are welcome.** If a resource doesn't fit an existing category, suggest a new one with a short section description.

## What belongs here

- Task mining tools (commercial or open source)
- Research papers about task mining, UI logging, or desktop activity analysis
- Tutorials, guides, and blog posts that teach task mining concepts
- Datasets and benchmarks for task mining research
- Conferences, workshops, and communities focused on task mining

## What doesn't belong

- Generic process mining resources (those go in [awesome-processmining](https://github.com/TheWoops/awesome-processmining))
- Employee surveillance or monitoring tools that don't focus on process improvement
- Paid courses or paywalled content without a free summary or abstract
- Tools that have been discontinued without an open-source successor

## Quality check

Before submitting, ask yourself:

- Would someone new to task mining find this useful?
- Is this resource actively maintained (for tools) or still relevant (for papers)?
- Does it add something not already covered by existing entries?
